# **SpeakOut - Aplicación de Accesibilidad Móvil**

## **Descripción**
**SpeakOut** es una aplicación móvil desarrollada en Android Studio con **Kotlin**, diseñada específicamente para personas con discapacidad sensorial del habla. La aplicación convierte dispositivos móviles en herramientas de integración y comunicación, mejorando significativamente la calidad de vida de sus usuarios.

## **Objetivo Principal**
El propósito de SpeakOut es proporcionar un sistema de apoyo inclusivo que permita a las personas con discapacidad sensorial visual escribir y leer fácilmente, la aplicación se convierte en una plantilla base para futuros proyectos que deseen implementar funcionalidades específicas para este público.

---

## **Características Principales**
1. **Accesibilidad**:
   - Controles de zoom global para ajustar el tamaño del contenido.
   - Diseño adaptativo compatible a partir de Android 11.0.
   - Soporte para navegación en modo claro y oscuro.

2. **Autenticación de Usuarios**:
   - Pantallas para **Inicio de Sesión**, **Registro** y **Recuperación de Contraseña**.
   - Validaciones en tiempo real para garantizar la integridad de los datos.

3. **Diseño Moderno e Intuitivo**:
   - Interfaz desarrollada con **Jetpack Compose** y Material Design 3.
   - Colores vibrantes y accesibles.

4. **Mensajes de Retroalimentación**:
   - Uso de `Snackbar` para mensajes atractivos y contextuales.
   - Mensajes de error detallados para guiar al usuario.

5. **Gestión de Usuarios**:
   - Arreglo inicial de usuarios simulados con nombres y contraseñas.
   - Registro dinámico de nuevos usuarios.

---

## **Tecnologías Utilizadas**
- **Lenguaje de Programación**: Kotlin.
- **Framework**: Android Studio.
- **UI Toolkit**: Jetpack Compose y Material Design 3.
- **Gestión de Estados**: MutableState.

---

## **Instrucciones de Instalación**
### **Requisitos Previos**:
- Android Studio Arctic Fox o superior.
- Kotlin 1.5 o superior.
- Emulador o dispositivo físico con Android 15.0 (API 35) o superior.

### **Pasos**:
1. Clona este repositorio:
   ```bash
   git clone https://github.com/puffoide/DAM_SpeakOut.git
   ```
2. Ábrelo en Android Studio.
3. Compila y ejecuta en un dispositivo físico o emulador.
